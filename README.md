# Chat-Microreactor: A Large-Language-Model-Based Assistant for Designing Microreactor Systems


## Repository Structure
- `web_demo`: A user-friendly interface for web-based interaction.
- `data_projs`: Contains the core codebase for the toolkit.
  - `inn`: Text filtering and selection mechanisms.
  - `summarize`: Key information extraction and unit conversion.
  - `workflow`: The integrated self-optimizing process.
  - `data_process`: Data processing scripts for model training and validation.
