# Chat-Microreactor: A Large-Language-Model-Based Assistant for Designing Microreactor Systems
Welcome to the Microreactor System Optimization Toolkit, an innovative solution designed to expedite the development of microreactor systems for automated chemical synthesis. This toolkit harnesses the power of advanced machine learning techniques to streamline the extraction of critical parameters from scientific literature.
**The code is in the master branch, which is located at https://github.com/PanYongqi23/Chat-Microreactor/tree/master.**

## Project Aim
This project aims to bridge the gap between complex multiphase reaction challenges and efficient microreactor design by providing a self-optimizing workflow. Our goal is to empower synthetic chemists with a tool that simplifies the process of extracting and utilizing key system parameters.
